BRAM-ring: combined CPU implementation (22 October 2026)

Implementation and attribution
------------------------------
The candidate retains the scalar lane-major tap loads from our CPU commit
285876608d09563ea5aa8e4fb992f277dab9e7dd, based on Peter Rizun's AVX2 verifier.
It adopts the aliased head/product pool and reverse tap-word accumulation
from kepler-ops-maker's MIT-licensed CPU submission
a15116f1a5bf92ad1caf3cb8070e4273554c4f14, and interleaves independent scalar
tap accumulators. Defaults: BRAM_TAP_GROUP=8, BRAM_REVERSE_TAPS=1.
The original MIT license and Peter Rizun copyright remain in LICENSE.
The competitor source is retained as an exact Git blob for comparisons.

The function, ring rotation, two-step DSP product delay, full-depth banks,
and number of bank read-modify-writes are unchanged. This is an implementation
speed optimization, not a claim to halve the specified work.

----------------------------------------------
Device: Intel i7-11850H, Lenovo ThinkPad P15 Gen 2i, Windows, 8 OpenMP threads.
Compiler: GCC 16.2.0, -O3 -march=native -funroll-loops -fopenmp.

use the same compiler flags, inputs and full-SHA harness in one executable.

These are local Windows measurements. The bounty is decided on Peter's

This local result establishes no official prize or reference-machine speed.
Earlier verified claims can raise the champion. Reusing MIT-licensed ideas
does not preserve the priority timestamp of an earlier different commit.

Reproduce from the repository root (Linux with GCC, OpenMP and Python 3)
---------------------------------------------------------------------
  gcc -O3 -march=native -funroll-loops -fopenmp \
    -o cpu/verify_combined_taps cpu/verify_combined_taps.c cpu/sha256.c
  cpu/verify_combined_taps vectors | python3 host/check_vectors.py
  OMP_NUM_THREADS=8 python3 cpu/compare_combined.py --mode verify --count 64
  OMP_NUM_THREADS=8 python3 cpu/compare_combined.py --mode bench --count 800 --runs 5

The helper also accepts --group, --reverse, --cc and --tables-dir.
For another epoch, regenerate with BRAM_EPOCH=<seed> python3 generate.py
in a scratch copy; never overwrite the frozen function files in a claim.
On Peter's reference CPU, pin the eight physical P-cores according to BOUNTY.md.
The standalone bench entry point also runs five full-SHA measurements.

Evidence files
--------------
cpu/proof/combined-2026-10-22 contains full per-run logs, build metadata,
source hashes, all-column vector outputs, the fresh reference vectors and
screening results. Timed work includes hash_state, little-endian serialization
of the full state and SHA-256 for every nonce. Table construction, allocation,
per-thread warmup and reporting checksums are outside the timer.

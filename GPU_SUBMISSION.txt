DESIGN
packed.py evaluates the twenty CA cells of each lane using sixteen
lane-wide rule masks and fifteen Boolean multiplexers. Tap index/shift
metadata is packed into uint16 and stored column-major.
packed_tiled.py changes the physical RAM layout only:
  index(row,lane) = (lane // TILE)*DEPTH*TILE + row*TILE + lane % TILE
TILE=32 is the measured configuration. The mapping is bijective over the
same B*DEPTH words; fill stores remain warp-contiguous. Fill and atomic RMW
use the identical mapping. Every specified cell evaluation and bank RMW
is retained. This is a speed implementation, not a counted-work shortcut.
